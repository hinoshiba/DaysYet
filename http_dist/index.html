DaysYet for Mac

作業のそばに、
時間の目印を。

画面の端で、今週・今月・今年の進み具合をひと目に。サークルにポインタを合わせると、残り時間と経過割合が広がります。作業の流れを止めずに、時間を確かめられます。

macOS 14以降

Mac App Storeでの提供を準備しています。

必要なときに、詳しく

サークルから、残り時間・経過割合・バーをまとめて確認。アプリでは3つの表示モードと4テーマから選べます。

自分の画面に合わせて

アプリでは左右・上端への配置と、80〜150%のサイズ調整に対応。左右の配置では、上下にドラッグして位置を変えられます。

Macの中だけに保存

今週・今月・今年は起動してすぐ表示。「勤務時間」や自分の目標も選べます。データはMac内に保存され、端末間の同期はありません。

DaysYet for iPhone / iPad

選ぶ。切り替える。
あとは、ひと目で。

画面の操作はシンプルです。見たい3つの時間、表示モード、テーマを選ぶと、ホーム画面ウィジェットのプレビューへそのまま反映されます。バー表示では右側の値も選べます。

iPhone / iPad features

3つの時間だから、迷わず見渡せる。

暦と自分の目標をホーム画面とロック画面へ。ホーム画面の時間、モード、値、テーマは、アプリ全体でもウィジェットごとでも選べます。

01

選べる3つの時間

今週・今月・今年・健康でいたい年齢から選択。必要になったら、大切な日の起算日と目標日時も追加できます。

02

3つの表示と4テーマ

時間だけ、残り時間・経過割合・バーの複合表示、バーだけを切り替え、鮮やかな夜や穏やかな森・朝・海から色を選べます。

03

ホーム画面とロック画面

ホーム画面はSmall・Mediumで3本、ロック画面はInline・Circular・Rectangularで選んだ1本を表示。ホーム画面ではウィジェットごとの上書きもできます。

Three steps

始め方も、3ステップ。

  1. 1
    時間を選ぶ

    アプリの「ウィジェット」タブで、ホーム画面に表示したい3本を並べます。

  2. 2
    見せ方を選ぶ

    ホーム画面では、3つのレイアウトと4つのテーマから組み合わせを選びます。

  3. 3
    画面へ追加

    ホーム画面には3本、ロック画面には追加後に選んだ1本を表示できます。

よくある質問

Mac版を始める

Mac版はmacOS 14以降に対応し、Mac App Storeでの提供を準備しています。公開前の動作はこのページのプレビューで試せます。Mac版ではDaysYetを起動すると、今週・今月・今年が画面の右端に表示されます。設定画面を閉じても常駐表示は続きます。本体をダブルクリックすると設定が開きます。macOSのウィジェットギャラリーから追加する操作は不要です。

Macで配置・表示内容を変える

ウィジェット本体をダブルクリックして設定を開き、表示する3つの時間、詳細の表示モード、プログレスバー表示時の値（残り時間・経過割合・終了日時）、テーマ、表示先ディスプレイ、左右または上端の配置、左右配置時の上下位置、サイズ（80〜150%、標準100%）を選びます。サイズに合わせてサークルと文字も変わります。項目にポインタを合わせると詳細が開きます。左右では選んだサークルの高さに合わせて、詳細と黒いパネルの膨らみが上下に移動します。上端ではバーやそのすぐ上にポインタを合わせて項目を切り替えられます。それより上のカメラ部分では、現在の項目の詳細が開きます。バーの帯と線の太さもサイズに合わせて変わります。本体のダブルクリックは設定を開きます。「詳細を開いたままにする」も設定で選べます。通常はポインタを外すと詳細が閉じます。「詳細を開いたままにする」を選んだ場合は、設定でオフにして閉じます。表示・非表示と終了は設定から操作できます。非表示にした場合は、DaysYetをもう一度起動すると設定が開き、表示を戻せます。

Macの常駐表示が見つからない

DaysYetをもう一度起動して設定を開き、常駐表示を有効にしてください。表示先ディスプレイと配置も設定で確認できます。改善しない場合は、MacとmacOSのバージョン、接続しているディスプレイ、再現手順を添えてお問い合わせください。

Mac版で週の始まりを変える

提供準備中のMac版では「設定 → 時間 → 週の始まり」から変更できます。初期状態は端末のカレンダー設定に従い、現在使われる曜日も表示します。日曜〜土曜のいずれかを指定すると、その曜日の現地時刻0:00から翌週の同じ曜日0:00までを「今週」として計算します。変更はMac版の残り時間・経過割合・終了日時に反映されます。

Mac版で毎日の勤務時間を設定する

提供準備中のMac版で開始・終了時刻を設定し、表示する項目から「勤務時間」を選びます。初期値は9:00〜18:00で、端末の現地時刻で毎日繰り返します。日中の勤務では開始前に「開始前」、勤務中に残り時間、終了後に「勤務終了」を表示します。22:00〜翌6:00のような勤務にも対応し、開始と終了が同じ時刻の場合は24時間として扱います。勤務時刻は端末内だけに保存され、他の端末には同期されません。

iPhone・iPad・Mac間で同期する

端末間の同期機能はありません。表示する時間や目標日は各端末で設定します。データの消去も操作した端末だけに反映されます。

ウィジェットを追加する

ホーム画面では空いている場所を長押しし、「編集」からDaysYetを検索してSmallまたはMediumを追加します。ロック画面では画面を長押しし、「カスタマイズ」からロック画面のウィジェット領域をタップしてDaysYetを追加します。Inline、Circular、Rectangularから選べます。

表示する時間を変える

アプリのウィジェットタブで3本を選ぶと、変更がホーム画面ウィジェットへ反映されます。特定のホーム画面ウィジェットだけ変える場合は、そのウィジェットを長押しして「ウィジェットを編集」を開き、「アプリで選んだ3本を使う」をオフにします。ロック画面で表示する1本は、ロック画面のカスタマイズ中にウィジェットをタップして選べます。

表示モードやテーマを変える

ホーム画面では、アプリのウィジェットタブで「時間」「時間＋％」「バー」から選び、4つのテーマを切り替えられます。「時間＋％」では、各行に残り時間、経過割合、左から伸びる進捗バーを一緒に表示します。特定のウィジェットだけ別の表示や色にする場合は、ホーム画面から「ウィジェットを編集」を開いて上書きできます。

大切な日の起算日を変える

アプリの「時間」タブから「人生の基準を編集」を開き、「大切な日」で起算日と目標日時を設定します。起算日を0%として、目標日時に100%となる経過割合を計算します。

表示が更新されない

一度DaysYetを開いて設定を保存し直し、ウィジェットがホーム画面またはロック画面に追加されていることを確認してください。OSが更新時刻を調整するため、常に秒単位で更新されるものではありません。改善しない場合は端末・OS・アプリバージョンを添えてsupport@hinoshiba.comへお問い合わせください。

データを消去する

iPhone / iPadでは設定タブ、Macではウィジェット本体のダブルクリックで開く設定画面で「すべてのデータを消去」を選びます。Macでは常駐パネルの配置とサイズの設定も初期状態へ戻ります。他の端末には影響しません。入力したデータは開発者のサーバーに保存されません。

Privacy · 最終更新 2026-09-06

入力した情報は、
この端末だけに。

要点: DaysYetは利用者データを収集・送信せず、追跡、広告、分析SDKを使用しません。入力した情報は端末内だけに保存されます。この方針は、提供準備中のMac版にも適用します。

設定画面から保存内容を確認し、いつでもすべてのデータを消去できます。

1. 保存する情報と目的

生年月日、健康でいたい年齢、目標名、目標の起算日と目標日時、毎日の勤務開始・終了時刻、週の始まりの設定、ウィジェットの項目、表示モード、値の形式、テーマを保存します。「勤務時間」の表示は任意で、勤務時刻は端末の現地時刻に基づく計算に使います。Mac版は常駐パネルの表示・非表示、表示先ディスプレイ、画面端の配置と位置、サークル・文字を含むサイズ、詳細を開いたままにする設定も保存します。時間の計算とアプリ・ウィジェット・常駐パネルの表示にだけ使います。

2. 保存場所と共有範囲

iPhone / iPad版はアプリとWidget Extensionが共有する端末内のApp Group領域に、Mac版はMacアプリ専用のサンドボックス内に保存します。端末間での同期はありません。開発者のサーバー、クラウド、分析・広告事業者、その他第三者へ送信せず、アカウントも作成しません。

ホーム画面・ロック画面のウィジェットやMacの常駐パネルは、端末を見ることのできる人の目に触れる場合があります。ロック画面では、端末がロックされている間も表示される場合があります。

3. 追跡・広告・分析

追跡、行動分析、広告、第三者SDKを使用しません。AppleがApp StoreやOSの提供に伴って処理する情報には、Appleのプライバシーポリシーが適用されます。

4. 健康に関する情報

「健康でいたい年齢」は利用者自身が決める計画上の目標です。HealthKitへアクセスせず、医学的診断、健康測定、治療、実際の寿命予測を行いません。外部の健康統計データも同梱していません。

5. 削除と保持期間

設定画面の「すべてのデータを消去」で、その端末の保存情報を直ちに削除できます。Mac版では常駐パネルの配置とサイズの設定も初期状態へ戻ります。他の端末のデータには影響しません。アプリ削除後に残る端末内データはOSが管理します。開発者は利用者データを受信・保存しないため、開発者へ削除請求を行う対象はありません。

6. 外部リンクと変更

利用者がソースコード、プライバシー、サポートへのリンクをタップした場合に限り、システムブラウザが開きます。外部通信、クラウド同期、クラッシュ解析、購入検証サーバー、HealthKit、第三者SDKなどを追加する場合は、この方針、Privacy Manifest、App Store Privacy回答を事前に更新します。

7. お問い合わせ時の情報

お問い合わせ先はsupport@hinoshiba.comです。利用者が任意にメールを送信した場合、送信元メールアドレスと本文を、返信および必要なサポート対応のために利用します。個人の日付、健康情報、認証情報、秘密鍵は送らないでください。脆弱性を報告する場合は、メール本文に詳細を含めず、安全な報告経路を依頼してください。
