Add the Widget

Touch and hold an empty area of the Home Screen, choose Edit, and add a Widget. Search for DaysYet, then choose Small or Medium.

Change the three timelines

Select three timelines on the app’s Widget tab. To override one Widget, touch and hold it, choose Edit Widget, disable “Use the three selected in the app,” and select its timelines.

The Widget is not updating

Open DaysYet once and save the settings again, then confirm the Widget remains on the Home Screen. The operating system schedules Widget refreshes, so values do not update every second. If the problem continues, include the device, OS, and app version in your request.

Delete data

Choose “Delete all data” from the Settings tab. No user data is stored on a developer server.
