# iPhone / iPadの設定動線

「時間」タブが時間の内容を管理し、「ウィジェット」タブはその一覧から表示する項目を選びます。ウィジェットに追加しても、新しい時間や独立した設定は作りません。

主なタブはこの2つです。どちらの画面でも右上のⓘは共通の「使い方」を下からシートで開き、時間の編集・ウィジェットの配置・ホーム画面への追加方法を確認できます。「閉じる」か下方向のスワイプで元の画面に戻ります。独立した「設定」タブは置かず、各画面の一覧の一番下に「このアプリについて」を置きます。通常の詳細画面として右から開き、左上の戻るボタンや画面左端からのスワイプで元の一覧に戻ります。ここからプライバシー・ソースコード・ライセンス・バージョン・データ消去に進めます。公開プライバシーポリシーへのリンクも残します。データ消去は確認ダイアログで確定し、両タブの詳細画面を閉じて初期設定へ戻ります。

| 入口 | 操作 | 反映する内容 |
| --- | --- | --- |
| ウィジェット → 3つの行／サークル | 表示形式を選ぶ | プレビューと、アプリに追従する設置済みの「DaysYet」ウィジェットを切り替え |
| ウィジェット → サークル → ＋ | 「時間から追加」で1つ選ぶ | 既存の時間をサークルに追加 |
| ウィジェット → サークル → 項目 | 一覧から時間を選ぶ | そのサークルの表示を差し替え |
| ウィジェット → 3つの行 → 行 | 一覧から時間を選ぶ | その行の時間を差し替え。ほかの行にある時間は位置を交換 |
| 時間 → 項目 | 内容を編集 → 保存 | 時刻・曜日・日付などを更新。同じ時間を使うすべての表示に反映 |
| ウィジェット／時間 → 右上のⓘ | 共通の「使い方」を下から開く | 時間の編集、ウィジェットの配置・追加方法を確認。「閉じる」か下方向のスワイプで元の画面へ戻る |
| ウィジェット／時間 → 一覧の一番下 | 「このアプリについて」を開く | プライバシー、ライセンス、バージョンなどを確認。データ消去は確認後に実行 |

## 画面の開き方

| 操作の役割 | 開き方・戻り方 | 対象 |
| --- | --- | --- |
| 操作の補足説明を読む | ⓘからシートを下から開き、「閉じる」か下方向のスワイプで戻る | 使い方 |
| 詳細を読む、即時反映の設定や項目選択へ進む | 右から開き、戻るボタン・画面左端からのスワイプで戻る。行の右矢印はこの遷移に使う | ウィジェットに表示する時間の差し替え・追加、アプリ情報、プライバシー・ライセンス文書、項目ごとの色、長押しからの色変更 |
| 下書きを編集して確定する | 編集の記号からシートを開き、「保存」か「キャンセル」で閉じる | 時間の時刻・曜日・日付などの編集 |
| 同じ画面で値を選ぶ | メニュー・選択部品で変更する | 表示形式、プレビューサイズ、表示方法、値、テーマ、システムの色・日付選択 |

「今週」の開始曜日は編集中の下書きに属する選択画面として右から開き、選択後に編集シートへ戻ります。初期設定は初回とデータ消去後の独立した画面として表示します。

## 初期設定

生年月日の入力前に、目標年齢までの残り時間の計算に使うことを短く説明します。同じ画面に健康目標のバーを1本表示し、生年月日・目標年齢の変更を即座に反映します。ここでのプレビューは下書きで、保存は「はじめる」を押したときです。次の画面では「今月・今年・健康でいたい年齢」の3本を確認できます。

「あとで設定」を選ぶと、「今週・今月・今年」で始めます。健康目標の未設定状態は保存し、仮の生年月日で残り時間や割合を表示しません。「時間 → 健康でいたい年齢」で入力して「保存」すると計算を開始します。「キャンセル」では未設定のままです。保存しても、ウィジェットで選んでいる時間は自動で入れ替えません。以前のバージョンで初期設定を済ませた人の生年月日・目標年齢は引き継ぎます。

「目標日まで」（旧「大切な日」）は初期設定に含めず、「時間」タブで設定します。試験・旅行・締め切りなど、指定した日までの残り時間を表示する項目です。入力済みの名前や日付は維持します。

## 時間を選ぶ画面

行の右矢印やサークルの＋から、選択画面を右から開きます。「時間」タブと同じ順序・名前・アイコンで一覧を表示します。各項目には残り時間を添え、表示中の時間や、3行表示で入れ替わる位置も示します。タップで選択を確定して元の一覧に戻ります。戻るボタンや画面左端からのスワイプでは、追加・差し替えを行いません。

この画面には時刻・日付・曜日のフォームを置きません。「『時間』タブを開く」では、選択画面を閉じて時間の一覧へ移動し、追加・差し替えは確定しません。時間タブにアプリ情報や色設定を開いたままでも、一覧に戻してから移動します。ウィジェットタブへ戻ったときも選択画面は残しません。

## 内容の編集と保存

- 活動時間の名前・時刻・曜日、学習日、健康年齢の目標、「目標日まで」の起算日・目標日時は「時間」タブで編集します。「保存」で反映し、「キャンセル」で破棄します。
- 編集中は下書きだけを変更し、保存するまでウィジェットに反映しません。変更がある間は編集シートをスワイプして閉じられません。
- 週の始まりは「時間 → 今週」で編集し、「保存」で反映します。「設定」タブには置きません。学習カレンダーの曜日順にも反映されることを説明し、選択した学習日や残り日数は維持します。今月・今年は編集ボタンにしません。
- ウィジェットの選択・並べ替え・削除・表示形式・テーマは操作時に保存します。サークルから削除しても「時間」の内容は残ります。
- 表示形式はアプリとウィジェットで共有して保存し、次回起動時にも引き継ぎます。プレビューのサイズは見本だけを変え、設置済みのサイズは変更しません。
- 3行表示とサークルの選択・配置は別々です。同じ時間を複数のサークルに置いても、その内容は共通です。

## 表示の整理

- 「時間」と「ウィジェット」は同じiOS標準のグループ付き一覧・上部バーを使います。「時間」の一覧とウィジェットの設定一覧では項目名を大きく上段に置き、残り時間はその下に小さく表示して、編集・配置する項目を探しやすくします。背景は初期デザインとHPの生成りに、淡いコーラル・琥珀色を重ねます。編集画面やアプリ情報にも共通の背景を使い、ダーク表示では深い紺に切り替えます。コントラストを上げる設定では淡い光を省きます。テーマの色は進捗表示とウィジェットのプレビューに使い、タブの背景は共通に保ちます。
- 4テーマの実際のプレビューを常時並べ、見本をタップして選びます。iPhoneは2×2、広い画面は横4つ、大きな文字では縦1列です。選択したテーマは枠とチェックで示します。サークルの小サイズは先頭4つ、中・大サイズは最大8つを表示します。
- パネルはライト表示で生成りの白、ダーク表示で背景より一段明るい紺に統一します。曜日選択・学習日・アプリ情報も同じ配色です。操作色はテーマに依存しないコーラルとし、明暗・コントラスト設定に合わせて文字と選択面の色を変えます。
- 三行とサークルは同じ背景と淡い光を使います。プレビューと実ウィジェットは背景の描画を共通化し、コントラストを上げる設定では光を省きます。
- テーマは3行表示とサークルで共通です。どちらの見本から選んでも両方に反映され、連動を切り替える設定は置きません。以前サークルに別のテーマを保存していた場合も、3行表示で使っていた共通テーマにそろえます。時間の並びと中央の値は維持します。
- 「項目ごとの色」と「時間」の長押しから個別の色を変更できます。テーマを切り替えても個別色は維持します。サークルは時間の色を引き継ぎ、個別に設定したサークルの色を優先します。色の編集画面にテーマ選択は重ねて置きません。
- 並べ替え中はプレビューと表示設定を隠し、行の文字を薄くせず、選択画面へ進む右矢印を外します。最後のサークルは削除できず、その理由を表示します。
- 大きな文字では、種類・プレビューサイズをメニューで選びます。時間の選択一覧も折り返してスクロールできます。

## 設置済みウィジェットとの連動

ホーム画面では「DaysYet」を追加します。アプリで表示形式・時間・テーマを選ぶと共有設定を保存し、WidgetKitに更新を依頼します。既存の3行ウィジェットも「アプリの表示に合わせる」がオンなら追従し、オフにした個別の3行設定は維持します。以前のサークル専用ウィジェットは「サークル（固定）」として残します。表示形式も連動させる場合は「DaysYet」を追加します。更新のタイミングはiOSが制御します。

実ウィジェットをシミュレーターで試す際も、アプリと拡張のApp Group登録が必要です。`build.sh`のiOS用ビルド・テストはアドホック署名を使用します。署名なしのビルドでは共有設定を読み込めず、仮表示のままになる場合があります。配布用の証明書や鍵は使いません。
