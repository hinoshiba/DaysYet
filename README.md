# DaysYet

**人生のTokenを、大切なことへ。**

今週、今月、今年、活動時間、学習日、健康でいたい年齢、大切な日から選び、時間があとどれだけ残っているかを静かに見渡すiPhone / iPad / Macアプリです。iPhone / iPadではホーム画面に3つの行または最大8つのサークル、ロック画面に1つを表示。Macでは画面端に常駐する時間から、必要な詳細を開けます。標準は3つで、左右の表示では設定から円を追加できます。3つの表示モードと4つのカラーテーマを選べます。

iPhone / iPad版は[App Store](https://apps.apple.com/jp/app/id6802000765)、Mac版は[Mac App Store](https://apps.apple.com/jp/app/id6802000765?platform=mac)で提供しています。Mac版はこのリポジトリからビルドすることもできます。

このREADMEはiPhone / iPad **0.1.9 (14)**・Mac **0.1.8 (12)** のソースを説明しています。iPhone / iPadでは3行と4サークルの編集を統一し、項目ごとの色設定と円内の名前表示を追加しました。0.1.9 (13)は2026-10-18 10:43 JSTにApp Reviewへ提出しましたが、追加のUI調整を含めるため取り下げ、同日18:22 JSTに「デベロッパにより却下済み」を確認しました。build 14はArchive・Apple Validate・アップロード・Apple側の処理を完了し、19:02 JSTに選択・保存、19:03 JSTに再提出しました。提出内容はiOS 0.1.9 (14)の1件で、「審査待ち」を確認しています。承認後に全ユーザーへ自動公開する設定ですが、0.1.9の承認・公開は未確認です。Macは0.1.8 (12)のままで、同日にApp Store ConnectのReady for Distributionを確認しています。[build 14再提出記録](AppStore/releases/0.1.9-build14.md) / [build 13提出履歴](AppStore/releases/0.1.9.md)

build 14では、iPhone / iPadの「時間」「設定」の見出しと背景を「ウィジェット」に統一しました。「時間」は大きなコピーを短い操作説明に整理し、文字サイズをアクセシビリティサイズにするとカードの項目名と値を縦に並べ、折り返して表示します。標語は初回案内と「このアプリについて」に残しています。この調整はbuild 13には含まれません。

## Features

- アプリで選んだ表示形式・時間・テーマをホーム画面ウィジェットに反映
- ホーム画面ウィジェットごとに3本、表示形式、テーマを上書き可能
- 「ウィジェット」タブは表示する時間の選択・配置を担当。サークルの＋では「時間」の一覧から1つ選んで追加し、項目をタップすると差し替え。「編集」で並べ替え・削除できます。3行表示も同じ一覧から選択。時刻・曜日・目標日などの内容は「時間」タブに集約し、「保存」で反映、「キャンセル」で破棄します。4テーマのプレビューを並べて見本のタップで選択できます。タブは「ウィジェット」と「時間」の2つです。プライバシー・ライセンス・バージョン・データ消去は「時間」画面右上のⓘから開きます。プライバシーポリシーとライセンスは「ウィジェット」画面右上のⓘから開く案内の下部にも置いています。[設定動線と保存の範囲](docs/SETTINGS_FLOW.md)
- 「DaysYet」ホーム画面ウィジェットは、アプリの「3つの行／サークル」の切り替えに連動します。置き直す必要はありません。サークルは1〜8つの時間を設定。小サイズは先頭の4つまで、横長の中サイズ・大サイズは8つまで表示し、個数に合わせて配置。アプリ内で3サイズをプレビューできます。時間の並びと中央の値は3行表示とは別に保存し、テーマは共通にします。どちらの見本から選んでも両方のテーマに反映されます。既存の時間の設定も引き継ぎます。新規ウィジェットはアプリ設定に従い、既存の3行の個別設定も維持します。以前のサークル専用ウィジェットは「サークル（固定）」として残り、個数・各時間・値・テーマの上書きを維持します。標準は今週・今月・今年・1日の活動と残り割合。スタンバイは小サイズを利用
- ロック画面ウィジェットには選んだ1本を表示
- 今週、今月、今年、2種類の活動時間、学習日、本人が設定する健康年齢の目標、起算日を指定できる任意の目標日時
- 週の始まりは端末のカレンダー設定に従うか、日曜〜土曜のいずれかを指定可能
- 2種類の活動時間に、それぞれ任意のラベル名、開始・終了時刻、有効な曜日を設定。曜日ごとのOffと日をまたぐ活動にも対応
- 短期の学習計画に、名前と期間を指定。学習できる曜日を選び、カレンダーの日付をクリック／タップして日ごとの追加・除外を調整。残りの学習日数と残り割合を表示
- カウントダウン／時間＋残り割合＋バー／プログレスバーの切り替え
- 色のある部分が残り時間を表し、100%から0%へ減少。バーは左端を固定して右端から左へ短くなり、右側の値を残り時間・残り割合・終了日時から切り替え
- 夜の彩り、静かな森、やわらかな朝、凪の海の4テーマ。「項目ごとの色」と「時間」の長押しから個別色を変更・リセットできます。サークルは時間の色を引き継ぎ、サークル用の個別色があれば優先します
- ホーム画面は3行表示・サークルともに`systemSmall` / `systemMedium` / `systemLarge`。ロック画面は`accessoryInline` / `accessoryCircular` / `accessoryRectangular`
- Macの画面端に常駐する、細い黒いパネル。左右には中央に残り割合を表示する円形メーター。12時の位置から時計回りに色が消え、残り時間に合わせて円弧が短くなる。標準は3つで、設定から重複しない時間を追加して最大8つまで表示し、3つまで減らせる
- Macでは小さな詳細表示が広がり、カウントダウン／時間＋残り割合＋バー／プログレスバーから表示モードを選択。プログレスバー表示では値を残り時間・残り割合・終了日時から選べる。左右では選んだサークルの高さに合わせて、詳細と黒いパネルの膨らみが上下に移動する。本体をダブルクリックして設定を表示。左右配置でグラフの拡大を有効にした場合も、クリックやダブルクリックでサークルを縮めず、ドラッグ開始時に拡大を解除して、離した位置で再び判定。詳細はポインタを合わせると開き、外すと閉じる。「詳細を開いたままにする」を選んだ場合は、設定でオフにして閉じる
- Macの表示先ディスプレイ、上下左右の配置、表示・非表示を設定。ドラッグすると、掴んだ項目へ全体が縮んで小さなサークル1つになり、カーソルに追従。各辺から画面の約1/4を吸着エリアとし、角の重なりでは実際に近い辺を選択。丸が画面の縁に触れる少し手前で吸着して押したままでも展開し、引き離すと再び丸へ集約。離したときに配置を保存。中央で離すかEscで元に戻る。左右の上下位置と下端の左右位置は別々に保存され、再起動後も保持
- 下端はサークルを横に並べ、画面の縁へ滑らかにつながる形で表示。ホバー時は同じ面が上へ広がり、上配置と同じ中央揃えの詳細を表示。開閉中も丸の位置を保ち、ホバー拡大と追加した円にも対応。左右・下端では縁に沿って動かす間は形を保ち、画面の内側へ引いたときに小さな丸へ変形。macOSのDock上では掴んだ丸1つで挿入位置を示す。Dock内の並べ替えは、離した後も既存の丸を不透明のまま表示。画面の辺から新しく入れるときは、配置が決まると全サークルが広がる。途中の棒状ハンドルや着地用の黒い土台は表示しない
- Macの「設定 → ウィジェット → 一般」に「ログイン時に起動」と、直接配布版の「アクセシビリティ」をまとめて表示。オン・オフ・承認待ちや許可状態をmacOSから読み取り、設定画面に戻ると更新する。アクセシビリティには「有効にするとDockにも設置できます」と説明し、システム設定を直接開ける
- Macの初回セットアップは「自動起動 → ドラッグ操作」の2段階。図で移動方法を説明し、直接配布版では続けてアクセシビリティの用途・設定手順・現在の許可状態を案内する。あとで設定することもできる。設定画面にはチュートリアルの再表示を置かず、「一般」から自動起動と権限を確認・変更できる
- 上端では設定の上から3つだけをMacのカメラ下に細いプログレスバーで表示し、詳細を開くときだけ下へ拡張。追加した4つ目以降は左右に戻すと再び表示。バーとその直上16ポイントにポインタを合わせて項目を切り替え。それより上のカメラ部分では現在の項目を開く。上端のバーの帯は標準で8ポイント、線の太さは2ポイントで、どちらもサイズ設定に合わせて拡大・縮小。カメラ部分の実寸は変えない。カメラのないディスプレイでは上端中央に配置
- Macのサイズは80〜150%（標準100%）で調整でき、サークルと文字も一緒に拡大・縮小。上端のバーの帯と線の太さも連動。詳細は全体サイズに対してさらに100〜150%（標準100%）で調整可能
- 左右・下配置のグラフの拡大は設定で有効にできるオプション（初期設定はオフ）。拡大率は110〜180%（標準135%）で調整でき、ポインタを重ねたサークルが画面中央側へ少し移動しながら拡大して、画面端で見切れないように表示
- 配置は上下左右の辺で選択。「Dock内」の独立した切り替えはなく、直接配布版ではmacOSのDockがある辺を選ぶとアクセシビリティの許可を確認してDock内へ入る。未許可の場合は設定変更・ドラッグを確定せず、元の配置を保って設定画面を表示。許可を取り消すとDockから取り出す。Dockでは各サークルが1枠ずつ使い、項目の追加・削除に合わせて増減する。丸をクリックすると共通のグループが開き、別の辺へドラッグすると全体がDockから外れる。アクセシビリティに対応しない通常ビルドではDock以外の辺へ配置できる。直接配布版ではDock内でも丸をまとめて並べ替え、他アプリが間に入った場合は操作後にまとまりを戻す。DaysYetの終了時には各アイコンも終了
- 直接配布向けの[Dock直接ドラッグ試作](Tools/DirectDock/README.md)を別途ビルド可能。アクセシビリティを許可するとDock内のどの丸からでも全体をまとめて取り出せる。Dock内で離すとその位置へグループを移し、通常の移動でDockを再起動しない。枠の角やOptionキー経由でもグループ移動になり、中央で離すかEscで元に戻る。Dockを離れる際は、固定されて残ったDaysYetの補助アイコンも削除する。通常のApp Store向けビルドには含まれない
- 日本語（primary / fallback）とEnglish
- VoiceOver、Dynamic Type、色だけに依存しない情報表示
- アカウント、広告、分析SDK、アプリからの外部送信なし
- 端末内データの全削除

「健康でいたい年齢」は利用者自身が決める計画上の目標であり、統計値、診断、健康状態や寿命の予測ではありません。

「活動時間」は2種類を個別に設定し、表示する項目から任意で選べます。新規利用時の初期値は、私用を含めた「1日の活動」（毎日7:00〜23:00）と「勤務時間」（月曜〜金曜9:00〜18:00、土日はOff）です。どちらもラベル名、開始・終了時刻、有効な曜日を自由に変更できます。従来の「勤務時間」を設定済みの場合は、時刻と表示する項目の選択を引き継ぎ、曜日は従来どおり毎日有効になります。

活動時間は端末の現地時刻で計算し、有効な日は開始前に「開始前」、活動中に残り時間、終了後に「活動終了」を表示します。無効な曜日は「Off」を表示します。22:00〜翌6:00のように日をまたぐ活動は開始日の曜日に従い、翌日がOffでも終了時刻まで続きます。開始と終了を同じ時刻にすると、有効な開始日から24時間として扱います。活動時間のラベル、時刻、曜日は各端末に保存され、他の端末には同期されません。

「週の始まり」はMacの「設定 → 時間」、iPhone / iPadの「時間 → 今週」で変更できます。初期状態では端末のカレンダー設定に従い、現在使われる曜日を画面で確認できます。曜日を指定すると、現地時刻のその曜日0:00から翌週の同じ曜日0:00までを「今週」として計算し、アプリ・Macの常駐表示・ホーム画面・ロック画面の残り時間、残り割合、終了日時へ反映します。学習カレンダーの曜日順にも使いますが、選択した学習日や残り日数は変わりません。

「学習日」はMacの「設定 → 時間 → 学習日を選ぶ」、iPhone / iPadの「時間」タブで「学習日」の項目をタップして設定できます。開始日・終了日を指定して学習できる曜日を選び、カレンダーで特定の日を追加・除外します。曜日を選ばず、日付だけを個別に指定することもできます。曜日順には「週の始まり」の設定を使います。開始日と終了日を含めて最長366日まで指定でき、2週間・4週間のショートカットも使えます。残り日数は今日を含む選択日数、残り割合は今日を含む残りの選択日数 ÷ 全選択日数です。曜日を変更すると個別の日付調整はリセットされます。学習日の名前、期間、曜日、日付ごとの指定は端末内に保存されます。iPhone / iPadでは個別編集の「保存」で反映し、「キャンセル」で破棄します。Macは自動保存です。これは利用できる学習日のカウントダウンで、実際に学習した時間や完了記録ではありません。

## Build

必要環境:

- iOS / iPadOS 17以降
- macOS 14以降（Mac版）
- Xcode 16以降
- XcodeGen 2.45.4

```bash
./build.sh project
./build.sh
./build.sh test
./build.sh mac
./build.sh test-mac
```

シミュレーターを指定する場合は`DAYSYET_SIMULATOR_ID=<UDID> ./build.sh test`を使えます。

`project.yml`がXcodeプロジェクト設定の正本です。生成される`DaysYet.xcodeproj`と共有schemeもコミットし、CIで生成結果の一致を確認します。設定を変更したら`./build.sh project`を実行し、両方を同じ変更に含めてください。上記のビルド・テストは配布用の証明書や鍵を必要としません。iOSシミュレーターでは、ウィジェットとの共有設定を有効にするアドホック署名を使います。署名情報はGit管理外の`Config/Signing.local.xcconfig`で設定し、App Store向けのArchive・検証・アップロードは、このMacのXcodeとOrganizerで明示的に行います。準備と手順は[ローカルXcodeリリース手順](docs/RELEASING.md)をご覧ください。

Mac版は`DaysYetMac` schemeでビルドします。Xcodeで`DaysYet.xcodeproj`を開き、`DaysYetMac`と「My Mac」を選んで実行してください。初回起動では画面の右端に今週・今月・今年を表示します。ウィジェット本体をダブルクリックして設定を開き、表示する時間と円の追加・削除、詳細の表示モード、プログレスバー表示時の値（残り時間・残り割合・終了日時）、テーマ、ディスプレイ、上下左右の配置、サイズ（80〜150%、標準100%）を変更できます。本体を掴んでドラッグすると、ポインタが重なっていた項目の小さなサークル1つに集約されます。上下左右の各辺から画面の約1/4が着地エリアで、角では近い辺が選ばれます。丸の直径の1.5倍を吸着判定に使い、見た目の外周が画面の縁に触れる少し手前で、押したままでも吸着して全体が開きます。そのまま縁に沿って動かすことも、引き離して丸に戻すこともできます。離したときに配置を保存します。中央で離すかEscを押すと元に戻ります。直接配布版では、アクセシビリティの許可後にmacOSのDockがある辺へドロップすると、丸の数ぶんのDockアイコンに切り替わります。未許可なら元の配置へ戻り、設定画面を表示します。それ以外の辺では従来のバーを表示し、Dockが左右にある場合の下端はサークルの横並びになります。Dockの丸をクリックすると共通のグループが開き、そこからドラッグして画面端へ取り出せます。直接配布版ではDock内の丸自体を掴んでも全体を移動できます。Dock上で掴んでいる間は小さな丸1つがカーソルに追従し、その位置で挿入する隙間を選びます。どの丸を掴んでも同じ隙間へ入ります。Dock内の並べ替えでは、離した直後から既存の全サークルを不透明のまま表示し、運んだ丸1つだけを確定した枠へ戻します。画面の辺からDockへ新しく入れる場合は、配置が決まると全サークルが広がります。着地中にDockの位置情報が一時的に途切れても運んだ丸の不透明度を保ち、Dock側の描画を待って表示を引き継ぎます。他の辺で離すとDockから取り出します。Dockを自動的に隠す場合は、最初にDockの丸をクリックすると位置を記憶します。上端のカメラ下では、設定の上から3つだけを表示します。サイズに合わせてサークルと文字も変わります。左右・下配置では「グラフの拡大」を有効にすると、カーソルを合わせたサークルだけがDockのように滑らかに拡大し、カーソルを離すと元の大きさに戻ります。初期設定はオフで、拡大率は110〜180%（標準135%）から選べます。拡大時は画面中央側へ少し移動し、画面端で見切れないように表示します。拡大を有効にした場合、サークルの拡大・縮小と詳細の開閉は同じ進行度で動き、詳細への移動中も拡大を保ちます。閉じている途中でカーソルを戻した場合は、その時点の大きさから滑らかに開き直します。「詳細のサイズ」は全体サイズに対してさらに100〜150%（標準100%）で調整でき、上下左右のどの配置でも使えます。macOSで「視差効果を減らす」が有効な場合は、アニメーションなしで切り替わります。設定画面を閉じても常駐表示は続きます。表示・非表示と終了は設定から操作できます。非表示にした場合は、DaysYetをもう一度起動すると設定が開き、表示を戻せます。「カラー」では4つの配色テンプレートを選ぶほか、項目ごとに好きな色を指定できます。色はプレビューと実際の表示にすぐ反映され、このMacに保存されます。項目単位、またはすべての色をテンプレートに戻せます。Mac版はネイティブの常駐アプリで、macOSのウィジェットギャラリーから追加するWidgetKit拡張ではありません。

## Repository layout

```text
Shared/                 日付計算、モデル、端末内永続化、共通翻訳
DaysYet/                iPhone / iPadのSwiftUIアプリ
DaysYetWidget/          iPhone / iPadのWidgetKit + AppIntent
DaysYetMac/             macOSネイティブアプリと常駐パネル
DaysYetTests/           共通ロジックの単体テスト
AppStore/               App Store Connect提出情報の正本
http_dist/              GitHub Pagesへ公開するWebページ
docs/                   公開可能な技術・コンプライアンス資料
Scripts/                検証、バージョン更新、スクリーンショット取得
project.yml             XcodeGenの正本
```

iPhone / iPad版App Storeのprimary languageは日本語、追加localizationはEnglish (U.S.)です。Mac版は既存のDaysYet掲載にmacOSプラットフォームを追加する構成で、両アプリのBundle IDは`com.hinoshiba.daysyet`を使います。設定データは引き続き各端末のサンドボックスに保存し、端末間では同期しません。提出用資料は[`AppStore/`](AppStore/)で管理します。Mac版の公開には、Mac向けのメタデータ・スクリーンショット・署名・動作確認が別途必要です。
