# macOS 0.2.2

Status on 2026-11-21: **macOS 0.2.2 (15) is in candidate preparation.** App Store Connect confirmed macOS 0.2.1 Ready for Distribution, and a new 0.2.2 draft was created on the existing DaysYet record. Archive, validation, upload, processing, App Review submission, approval, and public availability of 0.2.2 are not yet confirmed. This update targets macOS only; iOS remains 0.2.1 (17).

## Changes and source

- Widgets can be dragged between displays, with the destination display and position saved after release. Canceling returns to the original display and position.
- Edge attachment, travel, and unfolding are slower and smoother, making movement easier to follow.
- Existing dates, schedules, colors, and display preferences are preserved.

Preparation began from main `3731112`, which merges the multi-display fix in [PR #63](https://github.com/hinoshiba/DaysYet/pull/63) and the edge-motion adjustment in [PR #64](https://github.com/hinoshiba/DaysYet/pull/64). The exact archived release commit and immutable release tag will be recorded after source preparation and verification are complete.
