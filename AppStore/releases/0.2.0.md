# iOS and macOS 0.2.0

Status on 2026-11-07: **iOS / iPadOS 0.2.0 (16) and macOS 0.2.0 (13) are Waiting for Review.** Final Submit for Review succeeded at 16:22 JST for iOS and 16:15 JST for Mac. Each receipt confirms the exact platform/build and one submitted item. Both platforms are configured for automatic release after approval to all users. Approval and public availability are not yet confirmed.

App Store Connect confirmed the previous iOS 0.1.10 (15) and macOS 0.1.8 (12) versions Ready for Distribution before this update. Existing names, Productivity/Lifestyle categories, free pricing, 175 available regions, and review contacts are retained. The published privacy label remains No Data Collected and the global age rating is 4+.

## Changes

- iOS unifies the row/circle widget editor, supports one to eight circles and all three Home Screen sizes, shares four live theme previews, and refreshes Widget/Times navigation. The info guide is a sheet; timeline selection uses push/Back navigation. Existing explicit widget choices and custom colors are preserved.
- Mac adds magnetic dragging between available screen edges, bottom placement, first-run movement guidance, and pointer/display improvements. The App Store build excludes direct-distribution Dock dragging and does not request Accessibility or Screen Recording access. The macOS Dock's edge is unavailable.
- Both platforms use 0.2.0. The Mac version helper now updates embedded Dock helper template versions together with the main Mac target, so packaged component versions remain aligned.
