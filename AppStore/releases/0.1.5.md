# 0.1.5 (8) iOS・macOSリリース準備記録

iOS / iPadOSとmacOSの **0.1.5 (8)** の提出資料を準備しています。2026-09-11のこの資料更新時点では、今回のArchive、アップロード、Appleによる処理、審査提出、公開の完了を記録していません。実際の結果は各段階の確認後に追記します。以前の提出状況は[0.1.4 (7)の記録](0.1.4-build7.md)に残しています。

## 変更内容

- 両プラットフォームに「学習日」を追加。名前と開始日・終了日を設定し、曜日で一括選択後にカレンダーの日付を追加・除外できる。両端を含めて最長366日で、2週間・4週間のショートカットを用意。
- 学習日の残りは選択された今日を含み、経過割合は過去になった選択日数を全選択日数で割った値。学習実績や完了の記録ではない。予定未選択と予定終了を区別し、端末の予定表へのアクセスは行わない。既存の表示項目は保持。
- iOS / iPadOSでは「設定 → 時間の基準 → 学習日を選ぶ」から編集し、アプリとホーム画面・ロック画面のウィジェットに表示できる。ホーム画面の表示項目数はこれまでどおり3つ、ロック画面は1つ。
- Macの円形メーターは標準の3つから、学習日を含む重複しない8種類まで追加でき、最小は3つ。左右ではすべてを表示し、上端・カメラ下では一覧の上から3つだけを表示・選択する。4つ目以降の設定は保持。
- Macでは表示中の時間ごとに色を選択可能。4つの配色テンプレート、個別の色リセット、全体のリセットを用意。テンプレートの選択は全項目のカスタム色を置き換える。変更は即時反映・保存。
- Macの「設定 → ウィジェット」の先頭に「ログイン時に起動」を追加。利用者が有効・無効を変更でき、承認待ちや変更失敗時にはmacOSのログイン項目設定を開ける。システム設定の変更はアプリに戻ると反映。
- Mac設定の上下位置スライダーを削除。左右の本体をドラッグして上下位置を調整する操作、位置の保存、中央に戻す操作を維持。
- iOS / iPadOSのアプリ、Widget、テストと、Macのアプリ、テストのバージョン・ビルド番号は0.1.5 (8)で統一。

## 提出資料

- iOS / iPadOSとmacOSの日英説明文、プロモーション文、リリースノートを今回の機能に合わせて更新。
- 両プラットフォームの英語審査メモに学習日の確認手順を追加。Macは3〜8サークル、上端の3項目制限、個別カラー、ログイン時起動、ドラッグによる上下移動の操作を記載。
- 学習日のUI設計と開発時の検証は[学習日タイマーのUI検証](../../docs/STUDY_DAYS.md)を参照。この過去の検証記録は今回のArchiveや提出の検証結果ではない。
