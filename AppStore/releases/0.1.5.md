# 0.1.5 (8) ソース準備記録

iOS / iPadOSとmacOSのバージョンを **0.1.5 (8)** に更新するソース変更です。今回の作業はソースの変更とPRの作成・マージまでで、Archive、App Store Connectへのアップロード、審査提出、App Storeでの公開は行いません。以前の提出状況は[0.1.4 (7)の記録](0.1.4-build7.md)に残しています。

## 変更内容

- Macの円形メーターは標準の3つを維持し、設定から表示する時間を追加・削除できるように変更。重複しない7種類すべてを追加でき、最小は3つ。
- 左右の常駐パネルでは選んだ項目をすべて表示。上端のカメラ下では設定の上から3つだけを表示し、4つ目以降の設定は保持。
- Mac設定の上下位置スライダーを削除。左右に配置した本体をドラッグして上下位置を調整する操作と、再起動後の位置の保存は維持。
- iOS / iPadOSのアプリ、Widget、テストと、Macのアプリ、テストのバージョン・ビルド番号を統一。iOS / iPadOSの表示項目数はこれまでどおり3つ。

## 今後の提出準備

この記録は公開済みバージョンの変更や、ストアでの提供開始を示すものではありません。`AppStore`内の既存メタデータとスクリーンショットは以前の提出資料として保持しています。将来0.1.5を提出する場合は、Macの円追加・削除、上端の3項目制限、上下位置の操作に合わせて説明文・リリースノート・スクリーンショットを確認し、[ローカルXcodeリリース手順](../../docs/RELEASING.md)に沿って別途検証してください。
