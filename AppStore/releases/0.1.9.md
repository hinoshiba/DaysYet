# 0.1.9 (13) iOS / iPadOS App Review提出記録

2026-10-18 **10:43 JST**、iPhone / iPadの **0.1.9 (13)** の最終 **Submit for Review** が成功しました。App Store Connectで提出項目1件、**Waiting for Review（審査待ち）**、下書き0件と、対象がiOS 0.1.9・build 13であることを確認しました。承認後に自動公開する既存設定を維持しています。0.1.9のApple承認・公開は未確認です。

この提出はiOS / iPadOSのみで、Macは **0.1.8 (12)** のままです。同日、App Store ConnectでiOS・macOSの0.1.8がReady for Distributionであることを確認しました。[0.1.8の提出記録](0.1.8.md)と過去のソースタグは保持します。

## 更新内容

- 「3つの行」と「4つのサークル」を共通のウィジェット編集画面に統一しました。サークルの4枠、中央の値、配色をアプリ内で保存でき、新規ウィジェットはその設定を参照します。
- 「カラー」にプレビュー、4つの配色テンプレート、表示中の時間ごとの標準カラーピッカーを集約しました。3行とサークルの個別色を別々に保存し、サークルは3行の配色を引き継ぎながら一部だけ変更できます。個別・一括リセットに対応し、テンプレート選択はその表示形式の個別色を非表示の時間も含めて解除します。
- サークルの名前を円内の値の上に配置しました。名前と値の領域を制限し、長い名前は縮小・末尾省略で収め、VoiceOverでは全文を保持します。
- iOSがウィジェット背景を取り除いた場合は文字とトラックをシステム色に切り替えます。追加方法と既存ウィジェットへの反映方法は共通ヘルプにまとめました。

既存ウィジェットの明示的な設定と3行表示の保存済み設定は維持します。アプリに合わせる項目は「ウィジェットを編集」で「アプリの設定」を選びます。サークルの中央の値がすでに「アプリの設定」の場合は、新しい専用設定（初期値：残り割合）を参照します。

ウィジェットで特定のテーマを指定した場合は、そのテンプレートを使用します。色は時間の種類ごとに保存するため、同じ時間を複数のサークルに選ぶと同じ色になります。旧プロフィールには空の個別色を補い、不正な色や未知の時間だけを除外して他の設定を保持します。Macの色設定API・保存形式は維持します。

最低OSはiOS / iPadOS 17です。新しい権限、外部送信、依存ライブラリは追加していません。背景の半透明化、ロック画面の単色表示、スタンバイの夜間表示はiOSが制御します。[設定とウィジェットの案内](four-circle-widget.md)
