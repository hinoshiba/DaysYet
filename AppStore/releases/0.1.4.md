# 0.1.4 リリース準備

今回の提出対象はiOS / iPadOS 0.1.4 (6)です。Macソースも0.1.4 (6)ですが、今回のiOS審査提出には含めません。2026-09-08、App Store ConnectでiOS 0.1.3 (5)とmacOS 0.1.2 (3)がともに「配信準備完了」であることを確認しました。0.1.4は提出準備中で、Archive、アップロード、審査提出の完了はまだ記録していません。日英のiOSストア説明、プロモーションテキスト、リリースノート、審査メモを今回の候補に更新しました。過去の提出履歴は[リリース記録](../review/release-readiness.md)を参照してください。

## 変更内容

- 「勤務時間」を2種類の「活動時間」に拡張。それぞれラベル名、開始・終了時刻、有効な曜日を変更可能。
- iOSの時間編集への入口を「設定」内の「時間の基準」に統一し、Times画面の重複した編集ボタンを削除。
- 新規利用時は「1日の活動」（私用を含む毎日7:00〜23:00）と「勤務時間」（月曜〜金曜9:00〜18:00、土日はOff）を用意。
- 既存の勤務時刻と表示項目の選択を引き継ぎ、従来の勤務時間は全曜日有効のまま保持。
- 日をまたぐ活動は開始日の曜日に従い、翌日がOffでも終了まで継続。開始と終了が同じ時刻なら24時間。終了時の表示は「活動終了」に統一。
- iPhone / iPadアプリ、ホーム画面・ロック画面ウィジェット、Mac設定と常駐パネルに反映。ラベル、時刻、曜日は端末内だけに保存し、端末間の同期は行わない。

## リリースノート

### 日本語

活動時間を2種類設定できるようになりました。私用を含めた1日の活動と勤務時間など、それぞれに好きな名前、開始・終了時刻、活動する曜日を設定できます。曜日ごとのOffや日をまたぐ活動にも対応し、これまでの勤務時刻と表示設定も引き継ぎます。日付や活動時間の編集への入口を「設定」内の「時間の基準」にまとめました。

### English (U.S.)

You can now set up two activity schedules, such as your whole day and work hours. Give each one a custom name, start and end times, and active weekdays. Set individual weekdays to Off and use overnight schedules. Your existing work times and display selections are preserved. Editing dates and activity schedules now starts in one place: Settings > Time reference points.
