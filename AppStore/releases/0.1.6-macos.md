# macOS 0.1.6 (9) release candidate

This candidate contains the optional side-graph magnification and synchronized
detail transitions merged in PRs #22–24. Only the Mac app and Mac tests move to
0.1.6 (9); iOS / iPadOS and its Widget remain at 0.1.5 (8).

## Changes

- Optional left/right hover magnification, off by default, adjustable from
  110–180% with a default of 135%. The selected circle moves inward as it grows.
- Circle enlargement and detail opening, closing, and row movement start
  together. Detail text grows with the opening surface without clipped fragments.
- Independent detail size from 100–150% at every edge. Reduce Motion presents
  the resulting state without animation. Saved preferences are preserved.
- Japanese and English store copy and review instructions describe these controls.

## Candidate validation

The isolated release checkout was based on `80723b9`, excluding the development
checkout's uncommitted diagnostic logging. Xcode 26.6 (17F113) passed all 183 Mac
and 81 iOS unit tests. Release compliance and asset validation passed. A redacted
Gitleaks scan of the existing 41-commit history found no leaks.

The actual Mac views were checked in Japanese and English on both sides at five
opening fractions, with 180% graph magnification and 150% detail size. The settings
image is refreshed for this candidate; the other screenshots retain their
unchanged feature coverage. Screenshot provenance is recorded in the
[Mac screenshot notes](../macos/screenshots/README.md).
