# 0.1.8 (12) iOS・macOSリリース準備

2026-10-03時点で、iPhone / iPad・WidgetとMacの **0.1.8 (12)** を準備しています。バージョン・ビルド番号と日英の提出用テキストを更新した段階です。この記録はArchive、アップロード、App Review提出、Appleによる承認、公開を確認したものではありません。App Store Connectの既存ビルド番号を確認してから候補を確定します。

## 更新内容

- iPhone / iPad：小・大サイズで4つの時間を2×2に表示する「4つのサークル」ホーム画面ウィジェットを追加。標準は今週・今月・今年・1日の活動。左上・右上・左下・右下の時間、中央の値、テーマをウィジェットごとに選択できます。アプリの3つの時間とは別に保持し、既存の3行表示とロック画面ウィジェットも利用できます。[使い方](four-circle-widget.md)
- Mac：左右配置でグラフの拡大を有効にしたとき、サークルの拡大・縮小と詳細の開閉を揃えました。閉じる途中にポインタを戻すと、その時点の大きさから滑らかに開き直します。詳細へ移動するときも拡大を保ちます。
- Mac：クリック・ダブルクリックでサークルが縮む問題を修正。ダブルクリックで設定を開き、ドラッグで位置を変える操作を維持します。拡大の解除はドラッグ開始時に行います。
- 保存済みプロフィールと表示設定を維持。新しい権限、外部送信、依存ライブラリは追加していません。最低OSはiOS / iPadOS 17、macOS 14のままです。

実装は [PR #35](https://github.com/hinoshiba/DaysYet/pull/35)、[PR #36](https://github.com/hinoshiba/DaysYet/pull/36)、[PR #37](https://github.com/hinoshiba/DaysYet/pull/37) で取り込みました。この候補の準備はmainの`c24c0bd`から開始しています。

## Release notes

iPhone / iPad adds Four circles in Small and Large Home Screen widgets. Each position, center value, and theme can be configured independently; existing three-row and Lock Screen widgets remain available. Mac fixes keep circle magnification and detail animations in step and preserve circle size during clicks and double-clicks. Saved settings remain intact. Both platforms are prepared as 0.1.8 (12); this preparation record does not establish an archive, upload, review submission, approval, or public release.
