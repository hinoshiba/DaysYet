# 0.1.8 (12) iOS・macOS配布・提出記録

2026-10-03にiPhone / iPad・WidgetとMacの **0.1.8 (12)** をApp Reviewへ提出し、両版とも **Waiting for Review（審査待ち）** を確認しました。承認後に自動公開する設定です。Appleによる承認・公開は未確認です。

## 更新内容

- iPhone / iPad：小・大サイズで4つの時間を2×2に表示する「4つのサークル」ホーム画面ウィジェットを追加。標準は今週・今月・今年・1日の活動。左上・右上・左下・右下の時間、中央の値、テーマをウィジェットごとに選択できます。アプリの3つの時間とは別に保持し、既存の3行表示とロック画面ウィジェットも利用できます。[使い方](four-circle-widget.md)
- Mac：左右配置でグラフの拡大を有効にしたとき、サークルの拡大・縮小と詳細の開閉を揃えました。閉じる途中にポインタを戻すと、その時点の大きさから滑らかに開き直します。詳細へ移動するときも拡大を保ちます。
- Mac：クリック・ダブルクリックでサークルが縮む問題を修正。ダブルクリックで設定を開き、ドラッグで位置を変える操作を維持します。拡大の解除はドラッグ開始時に行います。
- 保存済みプロフィールと表示設定を維持。新しい権限、外部送信、依存ライブラリは追加していません。最低OSはiOS / iPadOS 17、macOS 14のままです。

実装は [PR #35](https://github.com/hinoshiba/DaysYet/pull/35)、[PR #36](https://github.com/hinoshiba/DaysYet/pull/36)、[PR #37](https://github.com/hinoshiba/DaysYet/pull/37) で取り込みました。バージョン・提出資料・スクリーンショットの準備は [PR #38](https://github.com/hinoshiba/DaysYet/pull/38) にまとめ、Archiveのソース候補はmainの [`b3af20ad`](https://github.com/hinoshiba/DaysYet/commit/b3af20ad21f515c3910a7673bbe8d897f187b0a8) です。

ソースタグ [v0.1.8-build12](https://github.com/hinoshiba/DaysYet/tree/v0.1.8-build12)（iOS）と [v0.1.8-macos-build12](https://github.com/hinoshiba/DaysYet/tree/v0.1.8-macos-build12)（Mac）は、どちらも`b3af20ad21f515c3910a7673bbe8d897f187b0a8`を指す注釈付きタグとして公開済みです。

## Release notes

iPhone / iPad adds Four circles in Small and Large Home Screen widgets. Choose each timeline independently, plus a center value style and theme for each widget; existing three-row and Lock Screen widgets remain available. Mac fixes keep circle magnification and detail animations in step and preserve circle size during clicks and double-clicks. Saved settings remain intact. Both 0.1.8 (12) archives passed validation and were uploaded, processed, and submitted. Both platforms are Waiting for Review with automatic release after approval. Apple approval and public release remain unconfirmed.
