# iOS and macOS 0.2.1

Status on 2026-11-11: **iOS / iPadOS 0.2.1 (17) and macOS 0.2.1 (14) are release candidates.** Archive, upload, processing, and review submission are not yet confirmed. App Store Connect shows the previous 0.2.0 versions Ready for Distribution on both platforms. The release owner requested the latest App Store update for both platforms.

## Changes

- iOS explains birth-date use, permits deferring healthy-age setup, previews the countdown and percentage live, and improves large-text scrolling. Deferred goals remain Not set until saved in Times.
- Mac supports all four screen edges while keeping the widget clear of the Dock. Dock-side/hidden-Dock detection, inset-edge sliding, and drag gathering/travel/unfolding are improved. The App Store build does not insert native Dock icons or request Accessibility or Screen Recording access.
- The former Milestone timeline is now Target date. Existing dates, schedules, display choices, and colors are preserved.

The functional changes were merged through [PR #59](https://github.com/hinoshiba/DaysYet/pull/59) and [PR #60](https://github.com/hinoshiba/DaysYet/pull/60). Release preparation starts from main `95f1d5d6c9a27d51fd2193b089759376d4b0a43c`.
