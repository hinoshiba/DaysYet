• Three rows and Four circles now share one in-app editor. Switch designs and follow the same order: preview, timelines, then display settings. You can also open it from Settings.
• Save the four circle timelines, center value, and theme in the app. Newly added circle widgets use these settings; individual widget overrides remain available.
• Colors brings together a preview, four palette templates, and a color picker for each timeline. Customize colors and reset them individually or together. Row and circle colors are saved separately, and circles can follow row colors.
• Circle names now sit inside each ring, in smaller text above the value.
• Improved text and track readability when iOS removes widget backgrounds, including in StandBy.
• Consolidated instructions for adding widgets and applying changes in the toolbar help.

To apply app settings to an existing circle widget, touch and hold it > Edit Widget and set each field to App setting. A center value already using App setting now follows the dedicated circle value setting, initially Remaining percentage. Your saved Three rows settings are preserved.

Custom widget colors apply when Theme is App setting; an explicit theme uses its template. iOS controls Lock Screen and StandBy color and background rendering.
